Описание проекта телеграм-бота по поиску достопримечательностей
Принцип работы бота следующий: пользователь отправляет свою геолокацию через специальную кнопку в Telegram, после чего бот обрабатывает координаты и находит ближайшие к нему объекты из заранее сформированной базы достопримечательностей. В ответ бот отправляет пользователю название объекта, его краткое описание, примерное расстояние и ссылку на маршрут с помощью картографического сервиса.
Работа над проектом включала в себя разработку базы данных, написание кода на Python с использованием Telegram API, настройку взаимодействия с картографическими сервисами, тестирование бота в разных условиях, а также сбор обратной связи от пользователей.
В результате получился удобный и функциональный инструмент, позволяющий быстро находить интересные места поблизости и прокладывать до них маршрут, что особенно актуально для туристов и жителей города, желающих разнообразить своё время.
